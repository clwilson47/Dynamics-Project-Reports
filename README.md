# Dynamics-Project-Reports
Reports for the Dynamics projects completed Spring 2024 in teams of 3

## Project 1 - Gravity
We utilized a tape measure and dropped pencils. 

## Project 2 - Projectile Motion
We utilized a soccer ball and kicked it to generate a projectile. 

## Project 3 - Friction Coefficient 
We measured the friction coefficient of our cell phones on a lap top lid. 

## Project 4 - Spring Constant
We utilized a rubber band acting as a spring and made measurements using phones of known weights and gravity. 

## Project 5 - Pendulum
We utilized a key lanyard to analyze a pendulum
